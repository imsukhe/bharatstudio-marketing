# BharatStudio Marketing

Parent-brand public website: BharatStudio home, Alerts and Companion product pages, pricing, resources, support, legal pages, SEO, and public documentation.

It must not contain creator dashboard code, public tip checkout, private API keys, payment-webhook logic, or internal architecture/security detail.

## Published surface

The static site has one parent-brand homepage and separate product surfaces:

- `/` — BharatStudio parent brand;
- `/apps/alerts/` — Alerts product and creator-direct support story;
- `/apps/companion/` — Companion web, mobile and desktop story;
- `/features/`, `/pricing/`, `/download/`, `/compatibility/` — product discovery;
- `/docs/`, `/docs/companion/`, `/setup/`, `/resources/` — public guidance;
- `/support/`, `/status/`, `/legal/` — public operations and policy entry points.

The previous public site supplied visual/content direction, but unsupported
historical pricing, commission, tax, platform and unrelated studio claims are
not carried forward. The current public wording follows the v1 launch
authority. Local implementation passing does not equal legal, provider, SEO,
support-operations or production-host approval.
